🚲 Bike Sales Data Analysis Project
Welcome to the Bike Sales Excel Project repository! This project explores customer demographics and purchasing behaviors to understand what drives bicycle purchases using advanced Excel techniques, data cleaning, pivot tables, and an interactive dashboard.

🎯 Project Overview
Objective: Analyze customer background profiles (income, age, marital status, commute distance, and education) to identify target segments for bike purchases.

Dataset: Contains 1,000+ customer records with multi-variable metrics covering socio-economic factors and buying decisions.

Tools Used: Microsoft Excel (Power Query/Data Cleaning, Formulas, Pivot Tables, Interactive Slicers, Dynamic Dashboard Design).

🛠️ Key Steps Performed
1. Data Cleaning & Preparation
🧹 Duplicate Removal: Cleaned raw data entries by identifying and removing duplicate rows to ensure analytical integrity.

🧩 Handling Missing Values & Standardization: Cleaned inconsistencies in categorical text columns (e.g., standardizing Marital Status from abbreviations like 'M'/'S' to 'Married'/'Single' and Gender values).

🔢 Custom Age Bracket Categorization: Implemented conditional Excel formulas (IF/nested logical statements) to segment customers into distinct lifestyle age groups:

🧑‍🎓 Adolescent (< 31 years)

👨‍💼 Middle Age (31–54 years)

🧓 Old (55+ years)

2. Data Analysis
📊 Pivot Table Aggregations: Built multi-level pivot tables to cross-examine core metrics:

Average customer income grouped by bike purchasing behavior and gender.

Customer age bracket distribution versus purchase choices.

Impact of daily commute distance and vehicle ownership on purchasing trends.

3. Dashboard Design
📈 Interactive Visual Charts: Designed dynamic column charts, bar graphs, and trend summaries mapping income vs. purchases.

🎛️ Slicer Integration: Connected interactive slicers for Region, Education, and Marital Status to allow real-time data filtering across all dashboard elements seamlessly.

💡 Key Insights & Findings
👨‍👩‍👦 Middle-Age Dominance: The Middle Age demographic forms the largest customer base and records the highest volume of bike purchases.

💰 Income Correlation: Customers who purchased a bike generally exhibit distinct average income thresholds compared to non-buyers, varying notably across gender lines.

🚴 Commute Impact: Customers with shorter commute distances (e.g., 0-1 Miles) show unique purchasing densities compared to those with longer commutes, providing clear direction for targeted marketing campaigns.
